# Physico-chemical-analysis-of-water-

Ce projet vise à analyser les caractéristiques physico-chimiques de l’eau le long du réseau hydrographique du bassin versant emboité de la Claduègne, situé en Ardeche, Franec, à partir de données mesurées sur le terrain lors d'une campagne réalisée le 26 mars 2025.

🗂️ Données de terrain
Des points d’échantillonnage ont été répartis tout au long du bassin selon les différents stratégies. À chaque point, les paramètres suivants ont été mesurés à l’aide d’une sonde WTW :
    1)Température de l’eau
    2)Conductivité électrique
    3)pH

📈 Objectifs
Ce fichier de code permet :
  d’analyser la signature physico-chimique des différents tronçons du réseau hydrographique,
  d’explorer les corrélations entre les paramètres mesurés,
  de mieux comprendre le fonctionnement hydro(géo)logique global du bassin.
